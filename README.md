# Vale Decide 2026

Projeto independente da TV Attual para cobertura eleitoral e observatório político regional.

## Arquitetura

- Frontend: React + Vite
- Banco/API: Supabase — projeto `TV Attual — Vale Decide 2026`
- Hospedagem prevista: Vercel
- Repositório: `Grupo-Lira-de-Comunicacao/vale-decide`

## Escopo inicial

- Candidatos por cidade e cargo
- Situação eleitoral
- Histórico e dados verificados
- Base regional: Caçapava, Taubaté, São José dos Campos e Jambeiro
- Evolução prevista para emendas, entregas, fontes e acompanhamento editorial

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
